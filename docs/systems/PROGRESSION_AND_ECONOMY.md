# Progression And Economy

Implements steps 61-70 of `docs/TBH_GAME_SPEC_1_TO_100.md`.

## Character Progression

Each character grows through:

- level
- ascension/star rank
- skill level
- role growth path

Role growth must be obvious. Tanks get sturdier, healers recover more cleanly, DPS gains burst clarity, and support improves party tempo.

## Account Progression

The account-level meta system is the **Rune/Talent Tree**. It should unlock:

- offline reward cap
- auto features
- extra taskbar slots
- small global stat bonuses
- region quality-of-life bonuses

## Base Progression

The base is **The Loomstead**, a cozy workshop-home where the player reweaves resources into long-term upgrades.

Base functions:

- produce crafting materials
- provide landmark buffs
- host NPCs
- display cosmetic progress
- support idle income

## Equipment

First equipment slots:

- weapon
- armor
- accessory/collar
- charm

Equipment must support build optimization without becoming unreadable.

## Rarity

Item rarity:

- Common
- Rare
- Epic
- Legendary
- Ancient/Mythic

Rarity should increase affix depth and identity, not create impossible progression walls.

## Affixes

Starter affix pool:

- cooldown
- crit
- healing
- shield
- speed
- offline reward
- soft currency gain
- skill charge

## Crafting Language

Crafting is not generic forging. It is "stitching", "mending", "reweaving", and "thread-setting". This keeps progression tied to Purralia's lore.

## Reward Layers

- Short-term: coins, tiny drops, chest fill.
- Medium-term: gear, skill levels, base upgrades.
- Long-term: collection, ascension, region restoration, cosmetics.

## Currency

The economy must separate:

- soft currency
- premium currency
- gacha ticket
- craft material
- event token

## Sinks

Good sinks:

- upgrades
- cosmetic crafting
- affix reroll
- base decoration
- event exchange

Bad sinks:

- forced repair timers
- punitive failure costs
- pay-to-unblock walls
