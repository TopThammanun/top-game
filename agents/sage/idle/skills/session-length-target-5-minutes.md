Setting doc §2.4 pins the target session at **3–10 minutes, roughly twice a
day**. Design the return flow to fit that: collect AFK chest → open 1–2
reward chests → apply upgrades → push one wave or region step → tick 2–3
daily tasks. Everything else (deep gear tuning, cosmetics browsing) is
opt-in and does not block the "I got somewhere" feeling.

The Phase-1 benchmark from the recommendations ("5 min session must feel
'want another'") is the acceptance test: if a first-time-back player can't
close the game after 5 minutes feeling like something changed, the loop is
too diffuse.

**Do:**

- Put the daily task tracker on the same screen as the AFK chest — one visit,
  visible progress.
- Cap the number of "must open" pop-ups on return at three; queue the rest
  behind an unobtrusive badge.
- Time the reward ceremony (chest open → orb sweep → summary) to under 8
  seconds; longer is cinematic, but 8s ceremonies twice a day for 90 days
  add up to hours of friction.
- Every session should end with a natural "come back later" beat — a timer
  showing the next AFK cap fill, or a task that unlocks tomorrow.

**Avoid:**

- Loop steps that only make sense after 20 minutes of engagement (rune
  planning, deep gear reroll) presented on the return screen.
- Long unskippable cutscenes on daily return. Ceremony once, then let people
  skip it.
- "Everything unlocked at once" first-return experience — pace unlock beats
  across the first few returns so the loop teaches itself.
